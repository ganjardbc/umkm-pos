## Why the Files in This Folder Are Good Examples

> File picks and Do/Don't below were proposed by Claude from the code (2026-10-03) — not yet confirmed by the team.

Landing is deliberately standalone: no `@umkm-pos/ui`, PrimeVue, or vue-router (see the root `CLAUDE.md`).
These two files cover its whole pattern — a section component plus the locale composable.

## Do

- A new section is one file: `src/components/<Name>Section.vue`.
- All visible text goes through `useLocale()`; add the same key to `src/locales/id.ts` and `src/locales/en.ts`.
- Style with Tailwind utilities and landing's own palette (`bg-cream`, `text-navy`, `text-primary`), always
  with a `dark:` pair.
- Composables keep their `ref` at module level so the state is a singleton.

## Don't

- Don't import from `@umkm-pos/ui`, PrimeVue, or vue-router.
- Don't write UI text directly in a template. Existing exception: the product name "UMKM POS" in
  `HeroSection.vue` — it is the brand, not translatable copy.
- Don't put API calls in the locale/theme composables.
