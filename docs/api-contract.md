## General Conventions

Everything below is taken from the code, not from the older document.

- **Base path:** `/api/v1` (`app.setGlobalPrefix('api/v1')` in `apps/api/src/main.ts`). Default port `3030`
  when `PORT` is not set.
- **Swagger:** `/docs` — the source of truth for the endpoint list and DTOs.
- **Auth:** `Authorization: Bearer <JWT>`. `JwtAuthGuard` is global; public routes are marked `@Public()`.
- **Other headers allowed by CORS:** `X-Outlet-Id` (active outlet; validated server-side),
  `X-Customer-Session-Token` (self-order session). A new custom header must be added to `allowedHeaders` in
  `main.ts`.
- **Authorization:** `@RequirePermission('<resource>.<action>')`, e.g. `product.create`, `shift.read`,
  `stock.adjust`, `transaction.update_status`.
- **Success:** `{ "success": true, "data": <handler result> }` (`TransformInterceptor`).
- **Paginated list:** the handler returns `{ data, meta }`, so the final shape is
  `{ "success": true, "data": { "data": [...], "meta": { "total", "page", "limit", "totalPages" } } }`.
  Query: `page` (default 1), `limit` (default 10, max 100) from `PaginationDto`.
- **Error:** `{ "success": false, "message", "code", "errors"? }` (`HttpExceptionFilter`). `code`:
  `BAD_REQUEST`, `UNAUTHORIZED`, `FORBIDDEN`, `NOT_FOUND`, `CONFLICT`, `VALIDATION_ERROR`, `INTERNAL_ERROR`,
  otherwise `UNKNOWN_ERROR`.

⚠️ `docs/api/api-contract.md` (the older document) gives the base as `/api`, puts `meta` beside `data`, and
uses `total_pages`. The code differs on all three — where they conflict, follow the code.

## Endpoints

Full per-endpoint list: Swagger at `/docs`, or `docs/api/api-contract.md` (with the caveat above).
Controller prefixes present in `apps/api/src` (all under `/api/v1`):

| Area | Prefix |
|---|---|
| Auth | `auth` |
| Tenant | `merchants`, `outlets`, `outlets/:outletId/tables` |
| User & RBAC | `users`, `rbac`, `settings` |
| Catalog | `products`, `products/categories` |
| Stock | `stock` |
| Transactions | `transactions`, `transactions/:transactionId/items` |
| Shifts | `shifts`, `shifts/:shift_id/audit-log`, `shifts/:shift_id/participants/:user_id/metrics` |
| Reports | `reports` |
| Other | `notification` (singular), `uploads` |
| Self-order (public, no controller prefix) | `customer-sessions/start`, `catalog/*` |
| Platform admin | `admin/auth`, `admin/dashboard`, `admin/merchants`, `admin/outlets`, `admin/users`, `admin/roles`, `admin/permissions` |

Per-endpoint request/response fields are deliberately not copied here so they cannot go stale — see the DTOs
in `apps/api/src/<module>/dto/`.
